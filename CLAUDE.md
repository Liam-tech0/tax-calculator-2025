## Stack

- **Vite 8 + React 19 + TypeScript** (strict mode, `noUnusedLocals`, `noUnusedParameters`)
- **Tailwind CSS v4** — configured entirely in CSS (`src/index.css` via `@import "tailwindcss"` + `@theme {}`). No `tailwind.config.js`. PostCSS uses `@tailwindcss/postcss`.
- **shadcn/ui pattern** — UI primitives live in `src/components/ui/` and are hand-written (not generated by CLI), wrapping Radix UI with `cva` + `cn()`.
- **Path alias**: `@/` → `src/` (configured in both `vite.config.ts` and `tsconfig.app.json`).

## Architecture

All state lives in **`src/hooks/useTaxCalculator.ts`**. It holds activity type, revenue, options (ACRE, versement libératoire), and purchases, then derives `taxBreakdown`, `tvaStatus`, and `abovePlafond` via `useMemo`. `App.tsx` destructures this hook and passes props down — no context or external state library.

**Data flow**: `constants/taxRates.ts` → `utils/taxCalculations.ts` → `hooks/useTaxCalculator.ts` → `App.tsx` → calculator components.

**Calculation logic** is pure functions in `src/utils/taxCalculations.ts` (`calculateTaxes`, `getTvaStatus`, `isAbovePlafond`). Keep it side-effect-free.

**Tax rates** are in `src/constants/taxRates.ts` as `ACTIVITY_CONFIGS`, keyed by `ActivityType`. Each entry contains all rates for that regime: `cotisationsSociales`, `cotisationsSocialesACRE`, `cfp`, `tfcc`, `versementLiberatoire`, `abattementFiscal`, `plafondCA`, `tvaSeuil`, `tvaSeuilMajore`.

## French Tax Rules (2025)

Rates apply to gross CA (revenue). If CA = 0, no charges.

| Régime | Cotisations | ACRE (50% off) | CFP | Versement libératoire IR | Plafond CA | Seuil TVA franchise |
|---|---|---|---|---|---|---|
| BIC Vente | 12.3% | 6.15% | 0.10% | 1.0% | 188 700 € | 85 000 € |
| BIC Services artisan | 21.2% | 10.6% | 0.30% | 1.7% | 77 700 € | 37 500 € |
| BIC Services commercial | 21.2% | 10.6% | 0.10% | 1.7% | 77 700 € | 37 500 € |
| BNC Libérales RG | 24.6% | 12.3% | 0.10% | 2.2% | 77 700 € | 37 500 € |
| BNC CIPAV | 23.2% | 11.6% | 0.20% | 2.2% | 77 700 € | 37 500 € |

**Key rules:**
- **TFCC** (chambre consulaire) only applies if CA ≥ 5 000 €. Rates: 0.015% (BIC vente), 0.48% (artisan), 0.044% (BIC commercial), 0% (BNC).
- **TVA franchise** — below `tvaSeuil`: exempt, invoice HT, mention "TVA non applicable — art. 293B CGI". Above `tvaSeuilMajore`: TVA immediately due. Between the two: still exempt but will become taxable if exceeded 2 consecutive years.
- **TVA déductible** on purchases only applies when the auto-entrepreneur is above the franchise threshold.
- **Versement libératoire** eligibility: RFR du foyer fiscal N-2 ≤ 28 797 €/part.
- **Abattement fiscal** (for barème progressif without versement libératoire): 71% BIC vente, 50% BIC services, 34% BNC.
- **ACRE** rates will be reduced to 25% reduction (instead of 50%) from 1 July 2026.
- BNC régime général rates rise to 25.6% from 1 Jan 2026; CIPAV to 24.0%.

## Adding a New UI Component

Hand-write it in `src/components/ui/` following the existing pattern: Radix UI primitive + `cva` variants + `cn()` + `React.forwardRef`. Install the corresponding `@radix-ui/*` package if needed.

## Extending Activity Types

1. Add the new key to the `ActivityType` union in `src/types/index.ts`
2. Add a corresponding entry to `ACTIVITY_CONFIGS` in `src/constants/taxRates.ts`
3. Add a label mapping to `ACTIVITY_TYPE_CATEGORY` in `ActivitySelector.tsx` if needed
